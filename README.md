# Weather TP

## Partie A — Comparaison JSON / XML

| Donnée               | JSON                         | XML                        |
|----------------------|------------------------------|----------------------------|
| Pays                 | "country"                    | attribut country           |
| Coordonnées          | "latitude" , "longitude"     | attributs lat, lon         |
| Altitude             | "altitude_m"                 | attribut altitude          |
| Modèle de capteur    | "type"                       | attribut model             |
| Température          | "temperature_celsius"        | measure type="temperature" |
| Conditions ciel      | "conditions"                 | measure type="sky"         |
| Vent                 | "speed_kmh", "direction_deg" | speed, "direction"         |
